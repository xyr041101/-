# design-kit · 前端设计启动包

从 0 起步做前端设计时，缺的不是 AI，而是**素材与约束**。这个仓库把"能被 AI 直接吃进去的约束"和"能反复复用的素材来源"固定下来，避免每次从空白开始。

## 怎么用（三步）

1. **定调**：从 `design-tokens.md` 选一套 token（或改主色），生成 `tokens.css`，让 AI 只在这个范围里出样式。
2. **取素材**：按 `references.md` 找参考图 / 图库 / 图标 / 字体；配图优先用真实摄影，不用 AI 凭空画。
3. **出页面**：先批量出 6 个方向 → 挑 1–2 个 → 只对选中的做精修。每页交付前过 `checklist.md`。

## 文件说明

| 文件 | 作用 |
|---|---|
| `design-tokens.md` | 设计变量基线：色板、字阶、间距、圆角、阴影、动效时长 |
| `tokens.css` | 可直接引入的 CSS 变量 |
| `references.md` | 参考站、免费图库、图标库、字体、组件库清单（含商用许可） |
| `prompts/ai-image.md` | 系列化出图提示词模板（工业 / 产品 / 背景 / 纹理） |
| `photos/README.md` | 关键词表 + 批量下载说明 |
| `photos/fetch-photos.py` | 按关键词从 Pexels 批量下载图片的脚本 |
| `checklist.md` | 页面验收清单（12 项硬指标） |

## 核心原则

- **不要一次性要成品**：AI 的强项是批量出候选，弱项是一次做对。
- **系列化优于单张**：同一批图必须共享色板、构图和光影，否则拼起来是灾难。
- **素材优先生**:真实照片 > 3D 渲染 > AI 生图。能用前两种就别用第三种。
- **约束前置**：把"高级、简洁"翻译成 HEX、字号、间距、留白比例，AI 才做得出来。
