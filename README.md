## 索引

### 设计（根目录）

| 文件 | 什么时候用 |
|---|---|
| `design-tokens.md` | 开新页面前，先定色板、字阶、间距、圆角 |
| `tokens.css` | 直接引到项目里，组件只引变量 |
| `references.md` | 找参考、图库、图标、字体、组件库 |
| `prompts/ai-image.md` | 要生成配图 / 系列图时 |
| `photos/README.md` | 搭素材池、挑图标准 |
| `photos/fetch-photos.py` | 批量抓图（Pexels） |
| `checklist.md` | 页面交付前逐条过 |

### Agent 协作（`agent-ops/`）

| 文件 | 什么时候用 |
|---|---|
| `任务卡模板.md` | 派活前开卡。目标句必须带验收条件 |
| `角色分工.md` | 定角色。早期只开三职，别七角色全上 |
| `验收与回滚.md` | 验收、回滚、“Agent 自称完成”时对账 |

### 自动化（`automation/`）

| 文件 | 什么时候用 |
|---|---|
| `SCL编码规范.md` | 写 S7-1200/1500 的 SCL 块，交付前自检 |
| `OPC-UA联调清单.md` | PLC / Node-RED / 上位机对接，按序排查 |
| `产线项目交接模板.md` | 系统交给别人，或自己半年后回头接 |

## 建议使用顺序

1. **做页面**：读 `design-tokens.md` → 套 `tokens.css` → 过 `checklist.md`
2. **派 Agent 干活**：`agent-ops/任务卡模板.md` 开卡 → 开发只改卡内文件 → `验收与回滚.md` 验
3. **工业项目交付**：`automation/产线项目交接模板.md` 填完再交

## 维护规则

- 只加会被重复使用的东西，不做资料搬运（收藏夹谁都会建，能省的思考才是资产）
- 每个文件开头写明“什么时候用它”
- 改了在文件内留日期；过期的直接删，不留着“以后可能有用”

## 不在本库的东西

- 具体项目代码（各自仓库里）
- 密钥、凭证（永不入库）
- 一次性任务的中间产物
