# AI 出图提示词模板

原则：**系列化**。一批图必须共享同一套色板、同一类构图、同一种光影，否则单独看还行，拼进页面就散。

每条模板都遵循这个结构：
`主体 + 场景 + 材质 + 光位 + 镜头 + 色彩基调 + 输出约束`

---

## A. 工业 / 产线实拍感

```
真实的 [电池模组装配线 / 机械臂焊接工位 / 控制柜内部]，冷白厂房照明，
顶部 LED 灯带产生均匀高光，浅景深压缩背景，
35mm 等效视角、略高于操作台的高度，
金属材质保留轻微划痕与指纹，不磨皮不美化，
冷灰主调，唯一暖色来自指示灯，
写实摄影，无 CGI 光泽，无水印文字
```

要点：写"划痕、指纹、灰尘"能立刻去掉 AI 的塑料感；写"光位"比写"光线好"有用。

## B. 产品棚拍（白底 / 灰底）

```
[产品名] 置于哑光浅灰背景，单侧 45° 柔光箱主光 + 右侧补光，
底部极淡接触阴影，产品边缘清晰无过曝，
材质纹理可辨（金属 / 橡胶 / PCB 绿油），
85mm 中长焦，正面略偏轴透视，
中性白平衡，饱和度克制，
商业产品摄影，无人物，无文字
```

## C. 抽象背景 / 视觉底纹（放文字后面）

```
极简抽象背景，[冷灰到浅蓝] 单向渐变，叠加极细的 [噪点 / 网格 / 等高线] 纹理，
无主体、无光斑、无粒子特效，
大面积留白，构图重心偏右上，
超清，适合作为网页首屏底层
```

要点：背景图必须"没有故事"，一旦有主体就会抢标题。

## D. 结构 / 原理示意（黑白线稿）

```
[设备名] 的工业结构爆炸图，等距视角，
黑白线稿 + 单一强调色标注关键部件，
细线 1px，透视统一，部件间距均匀，
白色背景，工程图纸风格，无阴影无渐变
```

## E. 图标 / 小插画（一套 6–12 个）

```
同一套图标风格：2px 均匀描边，圆角 4，等距视角，浅色填充 + 单一强调色，
统一 512×512 画布，四周留白一致，
共 [6] 个： [列举每个图标含义]，
扁平，无渐变，无投影
```

要点：一套图标必须在**同一次生成里**列出全部，分次生成必然风格漂移。

---

## 通用禁忌词（写进负面提示）

`动漫、卡通、3D 渲染感、CGI、霓虹发光、紫色渐变、玻璃拟态、塑料感、
过度磨皮、水印、文字、logo、多余手指、错误透视`

## 一致性技巧

1. 固定一段"风格描述"，每次只改主体部分，其余原样复制。
2. 有条件就用参考图（img2img / 参考图生图），比纯文字稳得多。
3. 一次出 4–6 张，只留 1 张，其余重跑——不要把"差不多能看"的留下。
4. 生成的图统一过一遍：降饱和 2–4%、锐化 +10、导出 WebP。
