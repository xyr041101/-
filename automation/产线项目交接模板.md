# 产线项目交接模板

> 用于把一个跑在现场的系统交给别人（或不熟悉的自己）。判据：接手的人只靠这份文档，能不能排查一个常见故障。

## 1. 基本信息

| 项 | 内容 |
|---|---|
| 项目名 | |
| 现场／产线 | |
| 交付日期 | |
| 对接人（甲方／乙方／集成商） | |
| 系统状态（运行中／试运行／停工） | |

## 2. 架构一句话

> 例：S7-1500 主控 → 交换机 → 工控机（Node-RED）→ MES 接口；HMI 直连 PLC。

配一张拓扑图，标清每层的协议与端口。

## 3. 设备与地址清单

| 设备 | 型号 | IP | 通讯方式 | 备注 |
|---|---|---|---|---|
| PLC | | | S7 / OPC UA | |
| HMI | | | | 分辨率 / 画面编号 |
| 工控机 | | | | 系统版本 |
| 视觉 | | | | 相机型号 / 触发方式 |
| 机器人 | | | | 控制器版本 |

## 4. 程序结构

- 程序块清单（每块一句话职责）
- 关键 DB 含义
- 报警码对照表位置
- 配方 / 参数存放位置

## 5. 数据流

| 数据 | 从 | 到 | 频率 | 格式 |
|---|---|---|---|---|

写清“谁写、谁读”，避免两个系统同时写一个寄存器。

## 6. 已知问题（必须写，不许美化）

| 问题 | 现象 | 影响 | 临时对策 | 是否已修 |
|---|---|---|---|---|

## 7. 变更记录

| 日期 | 改了什么 | 谁改 | 验证方式 |
|---|---|---|---|

## 8. 备份与回滚

- 程序备份位置与版本号
- 组态备份（含硬件）
- 参数快照
- 回滚步骤（写具体，不写“恢复备份”）

## 9. 现场注意事项

- 带电操作限制、安全互锁、不可触碰的开关
- 哪些操作会导致停线
- 停机与重启的正确顺序

## 10. 交接自检

- [ ] 接手人能凭文档找到 PLC 的 IP 并连上
- [ ] 能凭报警码表定位一条报警
- [ ] 能凭回滚步骤恢复上一版本
- [ ] 已知问题与实际现象一致
