# OPC UA 联调清单

> 适用：PLC / 上位机 / Node-RED / 第三方系统通过 OPC UA 对接。按顺序走，不要跳步。

## 1. 网络层

- [ ] 两端能 `ping` 通
- [ ] OPC UA 端口（默认 4840）可达：`Test-NetConnection - ComputerName <ip> -Port 4840`
- [ ] 防火墙双向放行，不是只管一边
- [ ] 跨网段时确认路由与 NAT，不要假设能通

## 2. 服务与端点

- [ ] 服务端 OPC UA Server 已启用
- [ ] 客户端能拿到端点列表（Endpoint）
- [ ] 确认用的是哪个端点的 Security Policy：“None” 只用于内网调试

## 3. 证书与安全策略

- [ ] 客户端信任服务端证书，服务端信任客户端证书（双向）
- [ ] 证书有效期正常，系统时间准确（时间偏差会导致签名校验失败）
- [ ] 生产环境不用 `None`，至少 `Basic256Sha256` + 签名

## 4. 浏览与变量

- [ ] 能浏览到目标节点，记下完整 `NodeId`（含 `ns=` 与 `s=`）
- [ ] 变量类型与数据模型一致（`Int16` / `Float` / `Bool` 不要混）
- [ ] 数组或结构体的读写方式确认过

## 5. 读

- [ ] 单次读对
- [ ] 批量读对（多节点一次拿）
- [ ] 读频率合理，不要用 10ms 轮询几十个点

## 6. 订阅

- [ ] 订阅建立成功，`SamplingInterval` 与 `PublishingInterval` 设定合理
- [ ] 数据变化上报的只有变化量（Deadband 生效）
- [ ] 高频变化点用订阅，不要用轮询

## 7. 写

- [ ] 写权限单独确认（很多配置默认只读）
- [ ] 写入带类型匹配，`Bool` 写 `1` 会失败
- [ ] 写入前确认 PLC 侧没有互锁会覆盖

## 8. 稳定性

- [ ] 断网（拔网线 / 禁网卡）后能自动重连
- [ ] 重连后订阅能重建，不是只有连接恢复
- [ ] 服务端重启后客户端能恢复
- [ ] 长时间跑 24h 看内存与句柄是否泄漏

## 常见现象与排查方向

| 现象 | 优先查 |
|---|---|
| 连不上、超时 | 端口／防火墙／端点地址 |
| 握手失败 | 证书互信、系统时间偏差 |
| 能连上但浏览不到节点 | 命名空间、权限、节点未启用 |
| 读回来全是 0 或旧值 | 读的是缓存节点（`Attribute` 参数错） |
| 订阅不触发 | 采样间隔过大、Deadband 过宽 |
| 写入报 `BadUserAccessDenied` | 节点权限或会话角色 |
| 跑几天后卡死 | 会话未关闭／订阅未释放 |
